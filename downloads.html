Remote support on Windows

Windows Quick Assist: nothing to install

Quick Assist is built into Windows 10 and Windows 11, so on most computers there is nothing to download. While you are on the phone with us:

  1. Open the Start menu, type Quick Assist, and open the app.
  2. Sign in with your Microsoft account if it asks you to.
  3. Enter the security code we give you on the phone.
  4. Click Allow when it asks whether to share your screen.

That is the whole setup. We can then see your screen and, with your permission, work the mouse and keyboard while you watch everything we do.

How we keep this safe: we only connect when you enter our code and click Allow. We never connect uninvited, and there is no code that works before we give it to you on the phone. You can end the session at any time by closing Quick Assist, and when the session ends, so does our access.

For other computers

RustDesk for Mac, Linux, and other systems

If your computer is not running Windows, or Quick Assist is not available, we use RustDesk. It is free and open source, and it works the same simple way.

Download RustDesk from rustdesk.com

  1. Download RustDesk from the official site linked above and run it. On most systems there is nothing to install before it opens.
  2. RustDesk shows an ID and a one time password on its screen. Read both of them to us on the phone.
  3. We connect using that ID and password, and you accept the session on your screen.

The password RustDesk shows is for that one session only. When you close RustDesk, the session ends and the password stops working.
