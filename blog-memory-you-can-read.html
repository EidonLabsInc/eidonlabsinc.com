Memory you can read: what Vesper remembers, and how forgetting works

A companion that remembers you is asking for trust. We think trust should come with a record you can open, so here is exactly how Vesper's memory works.

Back to the home page · More articles

What she keeps

Vesper remembers the people she talks with: their names, their games, their plans, the things they tell her plainly. Each person's memory is that person's own private store, kept in their own words, and it is never shared with anyone else. Conversation memory stays personal. What she knows about games lives in a separate store, organized by game and patch, and the two never mix.

Consent comes first

Ordinary conversation is remembered because that is what a companion is for. Sensitive matters, like health and money, are kept only with the person's express consent first. Nothing is quietly filed away about the tender parts of a life.

You can read it

What Vesper remembers about you is not a black box. It is a record, and it can be shown to you. If a line in it is wrong, it can be corrected against what you actually said. A companion who cannot show her work is asking for a kind of trust we would not give, so we do not ask for it either.

Forgetting is a real delete

When a person asks to be forgotten, the memory is deleted, not hidden, not archived under another name. When a trial or a subscription ends and is not continued, the same rule applies, and we say so plainly before it happens, never after.

Never for sale

Memory exists for one reason: so the companion knows the person she is talking with. It is never used for advertising, never sold, and never used to profile anyone. That is a design rule, written into how she is built, not a promise we keep only while it is convenient.

Why we build it this way

A companion sits inside a life, close to the things that matter most. The least it owes in return is honesty about what it holds. If you are comparing AI companions, ask each one the same questions we answered here: what do you keep, where does it live, can I read it, and when I say forget, is it gone? We are happy to be judged by the answers.
