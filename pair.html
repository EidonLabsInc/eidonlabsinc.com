Pair a TV

This page links the Vesper app on your TV to your trial account. It works with the same trial token as the chat tile on the home page and the phone app. Your token is kept in this page's memory for this visit only. It is never stored and never sent anywhere except to Vesper's own service.

Your trial token

Enter your trial token once, then use either pairing method below.

Get a code to type on your TV

Ask for a fresh code here, then type it into the app on your TV where it asks for a code from the sign-in page. The code works for ten minutes and can be used once.

Use the code your TV is showing

If the app on your TV is already showing a code, type it here instead. Linking it signs that TV in as you.

Notes

A linked TV speaks with Vesper as you, with your own memory and your own conversation, the same as the phone app. A TV linked with a trial token stops working when that trial token expires. You can link more than one TV with the same token.

No token yet? Trial places are by invitation. Email support@eidonlabsinc.com with the subject "Vesper trial" and your name, and we will write back with your trial token.
