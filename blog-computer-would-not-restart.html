The computer that would not restart

A client told us his computer sometimes refused to restart, and the only way back was to clear the BIOS and start over. So we read the machine's diary.

Back to the home page · More articles

Every Windows computer keeps a log of its own life: every start, every shutdown, every error, written down with timestamps whether anyone reads it or not. Most faults people describe as random are sitting in that log with a date and a cause. This one was.

The log showed a pattern across three weeks: four occasions where the machine had gone down dirty, never finishing its shutdown, and at the same minutes, errors from the controller that runs its solid state drive. A restart asks a lot of that controller. The drive would stumble at exactly the moment the machine needed it most, and the next start would fail until the settings were cleared by hand.

The board in that machine was running early firmware, the first release from when the board was new. The manufacturer's later firmware notes addressed, in so many words, boot failures on configurations like his and problems training large memory kits like his. His memory kit is large.

Here is what we did. First, we turned off a power saving setting that lets the drive's connection sleep, a known troublemaker with this class of fault, and verified the change held. Second, we prepared the current firmware update, checked its fingerprint against the manufacturer's published one, and staged it on his desktop with plain instructions for the one part that has to be done by hand at the machine itself, about fifteen minutes at his convenience. Third, his machine is now watched by our desk, so if it ever goes down dirty again, we will know the same quarter hour it happens instead of three weeks later.

The lesson is not really about firmware. It is that your computer has been keeping notes on its own health all along, and almost nobody reads them. A good support desk reads them first and guesses never.

If your machine has a habit you have learned to live with, a restart that fails, a start that takes forever, a fan that runs for no reason, it is probably already written down.
